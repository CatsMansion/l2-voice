# 学习路径量表（intake）· 构念、依据、边界

> 目的：在**还没有文本**的时候，先把配置选对。
> ⛔ 它不是测量工具。它给出的是**先验**，一旦有文本，全部作废、以实测为准。

---

## 1. 为什么这个量表能成立

不是拍脑袋。三条依据：

**（1）语言经历可自报，且有稳定效度。**
LEAP-Q（Marian, Blumenfeld & Kaushanskaya, *JSLHR* 50:4, 2007, 940–967）在 52 名多语成人和 50 名西英双语者上建立信效度，结论：
- 自报与实测**有可预测的关系**，自报可用；
- 但「要精确估计某项任务的表现，必须把具体的语言史纳入」，光靠一个总体自评不够 ← 这就是本量表存在的理由；
- ⭐ 一个反直觉的细节：**自报口语水平最能预测二语表现**，自报阅读水平最能预测一语表现。所以问「你写作几分」不如问「你怎么产出」。

**（2）各构念与写作成绩有可引用的相关系数。**
Kojima 的元分析（*L2 writing and its external correlates*）：

| 构念 | 与二语写作表现的相关 |
|---|---|
| **二语阅读理解** | **r = .588** [.516, .651] ← 阅读→写作最强的单一桥梁 |
| 词汇量（size） | r = .481 |
| 词汇深度（depth） | r = .525 |
| 一语写作能力 / 元认知策略 | 效应**极小**，补偿不了二语语言知识 |

⚠️ 同一份元分析里还有一条关键调节：**语法知识对低/中级学习者是更强预测项，词汇对高级学习者更强。** ⇒ 对已经读到研二的人，**词汇和语域比语法重要**。

**（3）到达年龄是硬分界线。**
de Kleine, Lawton & Fenster (2024)：**12 岁**前到达者写作接近单语母语者，12 岁后保留残余痕迹。
Doolan (2017, n=149)：Gen 1.5 的口语听力与单语者无法区分，但写作错误模式更像二语者。
Reid (1998)：ear learner 错在屈折词素、语域、按读音拼写；eye learner 错在语序、假朋友、L1 干扰。

## 2. 每道题在改什么参数

**原则：每题必须映射到一个输出。映射不上的题不许问。**

| 题 | 输出参数 | 依据 |
|---|---|---|
| 几岁开始学英语 | eye/ear 底色 | Reid |
| **几岁到英语国家** | **`marker_set`（zh / g15）** | de Kleine 2024 |
| 待了几年 | 弱校正（单独预测力弱） | 同上 |
| 在英语国家读完的最高阶段 | `marker_set` 复核 | 同上 |
| 每周学术阅读页数 | `calp_index` → `script_band` | r=.588 |
| 有反馈的大论文篇数 | `calp_index` → `script_band` | 输出侧 |
| 写作时先想中文还是直接写 | `main_failure`（transfer） | 迁移假设 |
| 系统学过语法吗 | eye/ear 底色 | Reid |
| 有人逐句批注过吗 | 语域输入量 | 启发式 |
| **能看出自己哪类问题** | `marker_candidates` | ⭐ 见下 |
| 专业 | 第一人称/hedging 预期 | 启发式 |
| 用 Firstly / In conclusion 吗 | 模板风险 | 启发式 |
| 有人说过你「像模板」吗 | 模板风险（**权重最高**） | 外部反馈 > 自评 |
| IELTS | 仅交叉校验，⛔ 不参与选档 | 测不出学术语域 |

### ⭐ 为什么问「能看出哪类问题」而不是「你写作几分」

两个理由：
1. LEAP-Q 已经证明总体自评只能做粗筛；**具体的、可核对的自我诊断**误差小得多。
2. 这一题的答案**可以被文本验证**——说「我经常 a lot of」，就去文本里数 `a lot of`。对上了说明自评准，可以对其他项加权；对不上说明自评系统性偏差，整张量表都要降权。

这是整套量表里唯一**自带校准回路**的一题。

## 3. 输出怎么读

```
指纹库        g15 / zh        → 决定用哪本指纹册
学术强度指数  0–6             → 阅读档位 + 有反馈输出档位
水平估计      B2+/C1/C1+/C2   → 人群先验，⛔ 不是你的分数
主短板        vocabulary / transfer / register / template
预期方向      只给方向          → 用来和实测对撞
置信度        0.45–0.9        → 上限 0.9，量表不可能更高
```

**四种主短板对应的动作完全不同：**

| 主短板 | 含义 | 该做 |
|---|---|---|
| `vocabulary` | 学术词汇量不够 | 补词汇 + 读文献，改写收益低 |
| `transfer` | 产出走翻译路径 | 换产出方式，植入 zh 迁移标记 |
| `register` | 口语体漏进书面 | 语域清理 + g15 低密度标记 |
| `template` | 语篇太规整 | **去模板化**，不是加错误 |

## 4. ⛔ 它做不到什么（必须对用户说）

| 不能 | 原因 |
|---|---|
| 测出你的实际英语水平 | 自评与实测只是「有可预测关系」，不是等号 |
| 测出你的词汇量 | 要跑 VST / VLT，本量表没有 |
| 测出 AI 率 | 本机没有检测器，量表更测不出 |
| 替代文本分析 | 它是先验，文本是证据。有文本时先验作废 |
| 处理自评系统性偏差 | 只能说「有偏差」，方向要文本才能定 |

**一句话必须写进交付：**

> 「这是根据你的学习经历推出来的先验配置。它选对了该用哪本指纹册，但不代表你的实际水平。
> 想准，给我三篇你写的东西。」

## 5. 冲突处理

量表**不许把矛盾平均掉**。以下情况必须打印冲突并追问：

| 冲突 | 追问什么 |
|---|---|
| 中学年龄到达，但没在英语国家读完中学 | 到底在当地读了几年？ |
| 说直接用英文写，但自评「看不出任何问题」 | 是真没问题，还是没被批注过？ |
| 学术阅读量高 + 大论文多，但仍说「先想中文再翻」 | 是不是只有写长文才翻译？ |
| 自评 IELTS 很高，但从未收到逐句批注 | 高分是不是靠应试技巧？ |

## 6. 用法

```bash
python scripts/intake.py --template > answers.json   # 拿骨架
# 填完
python scripts/intake.py --answers answers.json      # 诊断
python scripts/intake.py --answers answers.json --write profiles/   # 存 persona 草稿
python scripts/intake.py --ask                       # 交互式逐题问（15 题）
```

⛔ 有旧作文样本时，跳过量表，直接走 `calibration.md` 的 `--samples`。文本永远优先。
