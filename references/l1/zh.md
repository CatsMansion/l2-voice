# L1 指纹库 · 中文母语者英文写作

> 用法：先读 `references/mechanism.md` 第 3–5 节。这份文件只解决一个问题：
> **一个中文母语、海外读过几年书、人是努力的写作者，会在哪些地方留下痕迹。**
>
> ⛔ 这不是「中式英语错误大全」。那些属于 IELTS 5.5 的材料，用在这里会把论文改废。
> 本文件按**水平档**分层，默认只取 B 档（见 §0）。

---

## §0 三档分层

| 档 | 对应 | 痕迹长什么样 | 每千词密度 |
|---|---|---|---|
| **A** | IELTS 6.0 / 国内本科 | 时态混乱、复数漏、`I very like`、句子断裂 | 8–16 处 |
| **B** | **IELTS 6.5–7.0 / 海外 1–3 年 ← 默认** | 冠词特指漏用、介词搭配、双连词、套语、语域滑落 | **3–8 处** |
| **C** | IELTS 7.5+ / 海外 5 年+ | 只剩冠词在长名词短语里漏、罕见搭配、极小语域滑落 | 1–4 处 |

⛔ **A 档的条目在论文里一律禁用。** 一篇 4000 词论文出现 `I very like`，导师的结论不是「这人写的」，是「这人语言不合格」。

---

## §A 冠词系统（最可靠、最安全）

中文没有冠词系统，这是唯一一个「永远不会因为练习而彻底消失」的漏洞。**B/C 档的主力。**

### A1 · 特指名词前漏 `the`
- **原**：I collected the data from the school's server.
- **植入**：I collected data from school's server.
- **为什么**：汉语「我从学校服务器上收的数据」没有定冠词位。母语者靠语感补，二语者靠规则补，长句中规则会漏。
- **安全度**：⭐⭐⭐⭐ 读者只会觉得「略微粗糙」，不会觉得「英语差」。

### A2 · 泛指复数前多 `the`
- **原**：Students often struggle with academic writing.
- **植入**：The students often struggle with academic writing.
- **为什么**：汉语「学生」在主语位常被理解为定指，迁移成 `the + 复数`。
- **安全度**：⭐⭐⭐⭐ 母语者也常犯，但高频出现有 L2 味道。

### A3 · 抽象名词前加 `a/an`
- **原**：This requires further research.
- **植入**：This requires a further research.
- **为什么**：`research` 在汉语里可数化（「一项研究」）。
- ⚠️ 慎用：这条容易被读成「不可数名词搞不清」，属于 A 档。

### A4 · 长名词短语末尾漏冠词（C 档专属）
- **原**：the difference between the two groups' mean scores
- **植入**：the difference between two groups' mean scores
- **为什么**：短语越长，二语者的冠词监控越容易掉。
- **安全度**：⭐⭐⭐⭐⭐ 最像「高水平非母语者」，母语者也会这么写。

## §B 复数与一致（B 档少量使用）

### B1 · 数词后复数脱落
- **原**：across three semesters / 40 participants
- **植入**：across three semester / 40 participant
- ⚠️ 慎用：在论文里显眼。一篇最多 1 次，且放在不显眼的位置（图表说明、附注）。

### B2 · 长主语后的主谓一致
- **原**：The number of students who reported anxiety **was** small.
- **植入**：...**were** small.
- **为什么**：汉语无形态一致，长距离依赖时监控失效。
- **安全度**：⭐⭐⭐ 自然，但会被 Grammarly 标红。

---

## §C 介词与动词搭配（B 档主力，最像人）

这类错误的特点是**母语者不会犯，但读者不会因此觉得作者水平低**——因为搭配本身是任意约定的。

| ID | 错法 | 正确 | 中文来源 |
|---|---|---|---|
| C1 | `discuss about the issue` | discuss the issue | 讨论**关于** |
| C2 | `emphasize on` | emphasize | 强调**在** |
| C3 | `according to my opinion` | in my view | 依我看 |
| C4 | `in the contrary` | on the contrary | 相反 |
| C5 | `pay attention on` | pay attention to | 注意**在** |
| C6 | `be responsible of` | be responsible for | — |
| C7 | `consist in` (当「由…组成」用) | consist of | 在于/由…组成 混 |
| C8 | `provide sb. sth.` | provide sb. with sth. | 提供某人某物 |
| C9 | `the reason is because` | the reason is that | 原因是**因为** |
| C10 | `enter into the room` | enter the room | 进**入** |

**使用建议**：一次改写最多取 2 条，各用 1–2 次。⛔ 不要十条全上——那是语料库，不是人。

## §D 双连词与句法迁移（最强指纹，也最危险）

### D1 · `Although ... but ...`（虽然…但是…）⭐⭐⭐⭐⭐
- **植入**：Although the sample size was small, but the effect size was large.
- **为什么**：汉语必须成对使用关联词，英语只能留一个。这是**最不会误判**的中文母语指纹。
- **风险**：语法检查工具会标红；导师会看成笔误，不会看成能力问题。
- **用量**：全文 **1 次**，放在中间段落。

### D2 · `Because ... so ...`（因为…所以…）
- 同上。用量 ≤1 次，且不要与 D1 同时出现在同一段。

### D3 · 话题-评论结构
- **原**：This variable, I did not include in the first model.
- **植入**：This variable, I did not include in the first model.（保留）
- **为什么**：汉语「这个变量，我没放进第一个模型」是标准话题句。
- ⚠️ 在学术论文里这条**很像"刻意口语化"**，B 档慎用，C 档禁用。

### D4 · 动词名词化过度
- **原**：We improved the pipeline.
- **植入**：We made an improvement on the pipeline.
- **为什么**：汉语「做了改进」→ `make an improvement`。二语者偏爱轻动词 + 名词。
- **安全度**：⭐⭐⭐⭐ 自然，且**同时**是 AI 味（AI 也爱名词化）——⚠️ 这条是双刃，只在需要压"口语感"时用。

## §E 套语与话语标记（论文里最显眼，也最容易过量）

这些是中文英语教学直接灌进来的模板。**它们同时是低 perplexity 的来源**，所以用量必须严格控。

| ID | 套语 | 说明 | B 档用量 |
|---|---|---|---|
| E1 | `with the development of ...` | 中文作文万能开头 | ≤1（且不要放全文第一句） |
| E2 | `more and more + n.` | 「越来越多」直译 | ≤1 |
| E3 | `As we all know` / `It is well known that` | 诉诸共识 | 论文里 **禁用**（学术上不成立） |
| E4 | `Last but not least` | 高频且常误用 | ≤1，且只用在不重要的收尾 |
| E5 | `Firstly / Secondly / Thirdly` | 序数式列举 | ≤1 组 |
| E6 | `In conclusion` / `To sum up` / `All in all` | 段末收束 | ≤1 |
| E7 | `play an important role in` | 万能谓语 | ≤1 |
| E8 | `learn knowledge` | 学知识 | 论文里禁用（太低级） |

⛔ **E 类合计不要超过 3 处。** 超过就变成「模板作文」，比 AI 还容易被认出来。

## §F 语域滑落（C 档最像，B 档慎用）

高水平非母语者最真实的痕迹不是语法错，是**语域突然掉一档**：

- 学术段落里插一句 `This is really a big problem.`
- 用 `a lot of` 而非 `many / numerous`（中文「很多」不分语域）
- 用 `get` 替代 `obtain / receive`：`we got the results`
- 用 `thing / stuff` 指代具体概念
- 缩写突然出现：`don't`、`it's`（论文里正常应避免）

**用法**：全文 1–2 处，且必须落在**非关键句**（例子、过渡、脚注式补充）上，不能落在 thesis 句。

## §G ⛔ 禁用清单（一看就是装的）

| 不要做 | 为什么 |
|---|---|
| 实词拼写错误（*recieve*、*enviroment*、*thier*） | 读成「英语差 / 有障碍」，不是「L2」 |
| 随机时态漂移（同一段过去时现在时乱跳） | 读成「写作能力有问题」 |
| `I very like` / `I am very interest in` | A 档，论文里出现即判语言不合格 |
| 每条错误只犯一次、全文撒 8 种不同类型 | 伪随机噪声，本身是机器特征 |
| 把 `the` 全部删掉 | 均匀删 = 人为痕迹；要删就删在特定结构上 |
| 中文标点（，。）混进英文 | 是打字事故，不是 L2 特征 |
| 全角引号 | 同上 |
| 大小写错误 | 同上 |
| 模仿「中式语法」造长句（把中文语序硬翻） | 读成机翻，且机翻本身是 AI 高风险特征 |

## §H 组合配方（B 档 / 论文 / 1000 词）

一个能直接抄的配方：

```
主体陈述错误（选 1 类，用 3–5 次）：A1 长名词短语漏冠词
辅助搭配错误（选 1 类，用 1–2 次）：C1 discuss about 或 C9 the reason is because
句法指纹（用 1 次）：                D1 Although...but
套语残留（用 1–2 次）：              E1 或 E5
语域滑落（用 1 次）：                F 里的 a lot of
```

合计 7–11 处 / 千词。**类型数 = 4**（A1 / C / D1 / E）。
超过 4 类就拆掉一类。⛔ 类型数是硬约束，比总密度重要。

## §I 换母语时要改什么

同一个 skill 骨架，换 L1 只换这份文件。各语种的主要漏洞点（⚠️ **除中文外均为类型学推导，未做语料核验，启用前必须补查**）：

| L1 | 最典型的漏洞 | 最典型的套语 |
|---|---|---|
| 中文 | 冠词特指、介词搭配、双连词 | with the development of |
| 日文 | 冠词脱落 + 主语省略过度 + hedging 过密（I think / maybe 堆叠） | ～is difficult for me |
| 韩文 | 冠词、时态一致、敬语迁移导致的过度礼貌 | I think that... 起句、Also 起句 |
| 越南语 | 时态/复数标记全脱（无屈折）、介词 | 直译结构 |
| 阿拉伯语 | `and` 串联长句（run-on coordination）、冠词系统错配、介词 | — |
| 西班牙语 | 形容词后置、false friends（actually→actualmente） | — |
