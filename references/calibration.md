# 人格校准 —— 从使用者的旧作文提取笔迹

> 为什么必须做这一步：套 L1 模板得到的是「一个标准中国留学生」，不是「你」。
> 而答辩、viva、和导师比对作业时，穿帮的不是「不像留学生」，是「不像你自己」。

---

## 1. 样本要求

| 项 | 要求 |
|---|---|
| 数量 | 3–5 篇（≥8 篇边际收益很低） |
| 长度 | 每篇 ≥300 词 |
| 时间 | 优先取**同一阶段**的（都大二 / 都上学期） |
| 类型 | 优先**同一文体**（都是 essay，或都是 report） |
| ⛔ 不要 | AI 润色过的（Grammarly 深度改写也算）、翻译工具产出的、考试限时作的 |

判定「能不能用」的一句话标准：**你自己读一遍，觉得「这就是我写的」。**

### 1.1 样本和目标文体不一致时怎么办（2026-10-23 实测补充）

样本和目标文体的**全局统计量**（句长均值、短句比、段长 cv、标记密度）**不可跨文体移植**。
同类证据：一篇 2100 词营销审计样本句长 13.2 / 短句 40%，目标论文句长 22.2 / 短句 10%。
把样本的句长分布硬搬到论文上，等于把学术散文改成博客——这正是本 skill 第一次翻车的形态。

**分工规则**：

| 层级 | 跨文体能不能搬 | 例 |
|---|---|---|
| 全局分布（句长/cv/短句比） | ⛔ 不搬，以目标文体重建 | 论文必须保持 18–26 均值 |
| 局部构造（词组级习惯） | ✅ 搬，密度打七折 | `the N of X` 代 `X's N`、专名重复代替代词 |
| 连接词习惯 | ✅ 搬 1–2 类 | `However,` 当「而是」用 |
| 格式错误 | ⛔ 一律不搬 | 引文括号在句号后、编号标题混乱 |

**局部构造怎么量**（脚本没覆盖，手工数）：

```python
# 所有格偏好：作者是不是躲 's？
len(re.findall(r"\bthe \w+ of\b", t)) / words * 1000     # 样本 7.4 → 论文 3.0
# 代词回避：是不是反复用专名当主语？
collections.Counter(句首词).most_common(4)
```

命中「专名/主题词占句首 ≥8% 且少代词」⇒ 这是**话题优先**习惯，跨文体可以搬，而且它正好能治 `The` 起句单调。

⚠️ **样本是小组作业**（多人撰写）时，只有两个以上作者共用的特征才算；单人段落里的写法不能当人格。
⚠️ 样本和目标相隔超过半年时，优先信任更新的那篇——语言水平在变。

### 1.2 多人样本怎么切分归属（2026-10-23 实测可用）

小组作业别硬猜。先查**撇号字符**——两个作者几乎不会共用同一个键盘设置：

```python
for p in paragraphs:
    curly  = p.count("\u2019")   # ’ 弯撇号
    straight = p.count("'")      # ' 直撇号
```

实测案例：一份 2196 词的两人作业，弯撇号 19 处全在 A 的段落、直撇号 10 处全在 B 的段落，
**零交叉**。配合错误密度（B 块 11 处 / A 块 3 处）和章节交接点（5.0 是新一大节），归属即可定案。

同法可用：`“ ”` vs `" "`、全角标点、`–` vs `-`、`Oxford comma` 有无、空格数量习惯。

切完再比这三项——它们区分水平档最狠，比 AI 词表准：

| 指标 | 老手 | 新手 |
|---|---|---|
| 句首词种类 ÷ 句数 | 0.72 | 0.33 |
| 第一人称 / 千词 | 6.8 | 1.0 |
| 连接词 / 千词 | 1.0 | 9.4 |

**机制**：新手靠连接词和模板化开头补位，老手靠句首变化和第一人称撑场。
所以「降 AI 率」的正解是抬前两项、压第三项，不是改词汇。

## 2. 跑脚本

```bash
python scripts/l2metrics.py --samples "C:/path/to/my_essays" --json
```

输出里关注四块：

1. `metrics.sent_mean / sent_cv` —— 你的真实句长分布。**改写时必须落在这个区间**，不是落在我给的默认值。
2. `markers[]` —— 你自己真实存在的母语标记。**只许用这里出现过的类型。**
3. `markers[].papers_seen_in` —— 出现在几篇里。**出现在 ≥2 篇才算稳定特征**；只出现 1 篇的是偶发，别当人格。
4. `ai_tells_in_own_work` —— ⛔ 你自己旧文里就有的 AI 词。这些**不进 persona**，改写时要删。

## 3. 脚本查不出来的，人工补

脚本只能量「可正则化的」东西。下面这些必须**人眼读样本**逐个标注：

- [ ] 冠词漏用：在哪些结构上漏？（特指名词前？长名词短语末尾？）
- [ ] 段落形态：段长参差还是一致？topic sentence 在段首还是段中？
- [ ] 综述风格：罗列式还是批判整合？（见 `academic-zh.md` §1）
- [ ] 引用动词：实际用了哪几个？分布如何？
- [ ] hedging：位置在哪？成串还是单点？
- [ ] 第一人称：`I` 和 `we` 怎么切？稳定还是不稳定？
- [ ] 结论段：有没有「不足与展望」？
- [ ] 语域：有没有突然掉一档的句子？
- [ ] **有没有重复使用的口头禅式表达？**（这是最强的人格指纹，脚本查不到）

标完填进 `templates/persona-card.md`。

## 4. 校准后的闸门

有校准数据时，**用样本的中位数覆盖默认值**：

```
sent_mean   → 样本中位数
sent_cv     → 样本中位数 ± 0.08
short_ratio → 样本中位数 ± 0.06
l1_marker_per_1k → 样本实测 × (0.8 ~ 1.6)
l1_marker_types  → 样本里的稳定类型数（≥2 篇出现过的）
```

⛔ 不要用默认值去要求一个校准过的人。默认值只是没样本时的兜底。

---

## 5. 没有样本时怎么办

必须**明确告知降级**，不许静默用模板冒充校准：

> 「你没有提供旧作文，我按中文母语者 B 档的通用模板来做。这版能解决『不像 AI』，
> 但解决不了『不像你』。如果你有 3 篇以前写过的英文，给我，我重跑一遍校准。」

然后走 `references/l1/zh.md` §H 的默认配方（4 类标记、7–11 处/千词）。

## 6. 人格存档

校准产物写到 `profiles/<id>.md`（+ `.json`），下次直接读，不要重新推。

```
profiles/
  ronny-zh-2026.md      ← 人格卡（人读）
  ronny-zh-2026.json    ← 度量值（脚本读）
```

跨文档复用同一个人格，是指纹不漂的唯一办法。
